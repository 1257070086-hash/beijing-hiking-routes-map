# 小红书配图偏好配置

## 水印设置
```yaml
watermark:
  enabled: false
```

## 视觉风格偏好
```yaml
preferred_style: "notion"  # 简约线条、高信息密度、适合干货内容
```

## 布局偏好
```yaml
preferred_layout: "sparse"  # 1-2个要点，视觉冲击力强
```

## 语言偏好
```yaml
language: "zh-CN"  # 中文
```

## 配置说明
- **水印**: 不添加水印，保持画面简洁
- **风格**: notion风格 - 极简线条风格，适合职场/求职类干货内容
- **布局**: sparse布局 - 视觉冲击力强，适合封面和核心信息展示
- **语言**: 中文生成
