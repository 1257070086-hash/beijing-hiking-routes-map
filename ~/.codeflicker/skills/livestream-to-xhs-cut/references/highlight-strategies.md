# 精彩片段识别策略

本文档定义了从直播逐字稿中识别精彩片段的多维度评估体系。

---

## 评估维度体系

### 维度1：信息密度（Information Density）

**定义**：单位时间内包含的有效信息量

**权重建议**：30%

**识别指标**：

1. **数据类型**（每出现一次 +2分）
   - 数字：`10个`、`50%`、`3倍`
   - 时间：`2023年`、`半年内`
   - 金额：`100万`、`年薪30W`

2. **列举结构**（每出现一次 +3分）
   - 显性列举：`第一、第二、第三`
   - 隐性列举：`一是、二是、三是`
   - 多点阐述：`首先、其次、最后`

3. **专业术语**（每出现一次 +1分）
   - 技术术语：`算法`、`模型`、`架构`
   - 行业黑话：`MVP`、`PMF`、`OKR`
   - 缩略词：`AI`、`B端`、`SaaS`

4. **案例故事**（每出现一次 +5分）
   - 真实案例：`我们有个客户...`
   - 对比案例：`A公司vs B公司`
   - 反面教材：`某公司踩的坑`

**计算公式**：
```python
info_score = (
    数字_count * 2 +
    列举_count * 3 +
    术语_count * 1 +
    案例_count * 5
)
```

**高分示例**（信息密度20+）：
```
快手0-3年专项招聘的3个核心数据：

第一，HC增长50%，相比去年扩招1000+岗位
第二，算法岗占比从30%提升到45%，技术驱动明确
第三，平均年薪区间25-35W，对标头部大厂

对比字节和美团的数据会发现，快手的技术栈更垂直...
```

### 维度2：情绪高点（Emotion Peak）

**定义**：演讲者情绪波动和感染力的峰值时刻

**权重建议**：20%

**识别指标**：

1. **语气词密度**（每出现一次 +1.5分）
   - 强调词：`真的`、`非常`、`特别`、`太`、`超级`
   - 确认词：`确实`、`其实`、`竟然`
   - 转折词：`但是`、`然而`、`不过`

2. **标点符号**（每出现一次 +2分）
   - 感叹号：`!` `！`
   - 问句：`?` `？`（互动性）
   - 省略号：`...`（停顿强调）

3. **重复强调**（每出现一次 +3分）
   - 词语重复：`真的真的很重要`
   - 短句重复：`记住，一定要记住`
   - 反问重复：`为什么？为什么会这样？`

4. **互动性语言**（每出现一次 +2分）
   - 提问：`你们知道吗？`
   - 呼应：`对不对？`
   - 引导：`大家注意...`

**计算公式**：
```python
emotion_score = (
    语气词_count * 1.5 +
    感叹号_count * 2 +
    问号_count * 1.5 +
    重复_count * 3 +
    互动_count * 2
)
```

**高分示例**（情绪分15+）：
```
你们知道吗？真的很多人误解种地社文化！

不是加班！不是内卷！而是用技术让普通人被看见！

我特别喜欢这句话：技术不是让5%的人锦上添花，
而是让95%的人雪中送炭！

真的，这才是技术的价值所在！
```

### 维度3：金句识别（Golden Sentence）

**定义**：可独立传播的短句、名言型表述

**权重建议**：25%

**识别标准**：

1. **长度筛选**
   - 最佳区间：10-40字
   - 过短（<10字）：信息不完整
   - 过长（>40字）：难以记忆

2. **结构特征**（出现即 +5分）
   - 对仗式：`不是...而是...`、`不仅...还...`
   - 对比式：`A vs B`、`A不代表B`
   - 递进式：`从...到...`、`不只...更...`
   - 因果式：`因为...所以...`

3. **内容特征**（每出现一次 +2分）
   - 绝对词：`最`、`唯一`、`永远`
   - 本质词：`真正的`、`核心`、`本质`、`关键`
   - 价值词：`价值`、`意义`、`重要`

4. **传播潜力**
   - 可截图：短小精悍，视觉友好
   - 可引用：脱离上下文仍有意义
   - 可共鸣：触发普遍认同

**计算公式**：
```python
golden_score = 0
if 10 <= 字数 <= 40:
    golden_score += 结构特征_count * 5
    golden_score += 内容特征_count * 2
```

**高分金句示例**（得分10+）：
```
✅ "我们要的不是会写代码的人，而是能用技术改变生活的人"
   - 长度：28字
   - 结构：对仗式（不是...而是...）
   - 得分：5（结构）+ 4（内容：真正的、改变）= 9分

✅ "技术的价值不是让5%的人锦上添花，而是让95%的人雪中送炭"
   - 长度：32字
   - 结构：对仗式 + 数字对比
   - 得分：5（结构）+ 4（内容：价值、真正）= 9分
```

### 维度4:话题完整性（Topic Completeness）

**定义**：片段是否包含完整的话题阐述（起承转合）

**权重建议**：15%

**识别方法**：滑动窗口检测

**窗口大小**：10个句子（约30-60秒）

**评分标准**：

1. **话题开始标志**（出现即 +3分）
   - 引入词：`那么`、`接下来`、`现在`
   - 提问词：`为什么`、`怎么办`、`如何`
   - 序号词：`首先`、`第一`

2. **话题结束标志**（出现即 +3分）
   - 总结词：`所以`、`总之`、`因此`
   - 强调词：`记住`、`重点是`、`核心是`
   - 确认词：`明白了吗`、`清楚了吗`

3. **内容连贯性**（信息密度/5）
   - 复用"维度1：信息密度"的评分
   - 除以5作为连贯性附加分

**计算公式**：
```python
topic_score = 0
if has_start_marker:
    topic_score += 3
if has_end_marker:
    topic_score += 3
topic_score += info_density_score / 5
```

**高分示例**（话题完整性10+）：
```
[开始标志] 那么接下来说说种地社文化到底是什么

[内容展开] 
很多人以为种地社等于加班文化，这是最大的误解。
种地社的核心是用技术服务"种地的人"。
举个例子，春节红包功能，就是为了让普通人感受到温暖...

[结束标志] 
所以，记住这一点：种地社不是让员工种地，
而是用技术让真正种地的人被看见。明白了吗？
```

### 维度5：传播潜力（Viral Potential）

**定义**：内容在社交媒体的传播可能性

**权重建议**：10%

**识别指标**：

1. **争议性**（每出现一次 +2分）
   - 反转词：`但是`、`其实`、`相反`
   - 误区词：`误区`、`真相`、`你以为`
   - 颠覆词：`不要以为`、`别被骗了`

2. **共鸣性**（每出现一次 +1.5分）
   - 群体词：`我们`、`大家`、`很多人`
   - 共识词：`都知道`、`都说`、`普遍`
   - 渴望词：`谁不想`、`都希望`

3. **实用性**（每出现一次 +2分）
   - 方法词：`方法`、`技巧`、`建议`
   - 警示词：`注意`、`避免`、`千万别`
   - 推荐词：`推荐`、`如何`、`怎么`

4. **情感共振**（每出现一次 +2.5分）
   - 痛点词：`焦虑`、`困惑`、`难`
   - 爽点词：`爽`、`牛`、`厉害`
   - 惊奇词：`竟然`、`居然`、`没想到`

**计算公式**：
```python
viral_score = (
    争议性_count * 2 +
    共鸣性_count * 1.5 +
    实用性_count * 2 +
    情感共振_count * 2.5
)
```

**高分示例**（传播潜力15+）：
```
❌ 你以为应届生没经验就没竞争力？大错特错！

其实很多人都不知道，0-3年的社招反而处于尴尬期：
经验不深，价格不低。

真相是：应届生的可塑性才是最大的优势。

推荐方法：找准定位，避免盲目追求大厂光环。

谁不想毕业就进大厂呢？但更重要的是找到适合自己的...
```

## 综合评分体系

### 默认权重配置

```json
{
  "weights": {
    "information_density": 0.30,
    "emotion_peak": 0.20,
    "golden_sentence": 0.25,
    "topic_completeness": 0.15,
    "viral_potential": 0.10
  }
}
```

### 综合得分计算

```python
final_score = (
    info_score * 0.30 +
    emotion_score * 0.20 +
    golden_score * 0.25 +
    topic_score * 0.15 +
    viral_score * 0.10
)
```

### 分数等级划分

| 分数区间 | 等级 | 推荐度 | 说明 |
|---------|------|--------|------|
| 20+ | S级 | ⭐⭐⭐⭐⭐ | 必选片段，高信息密度+强传播潜力 |
| 15-20 | A级 | ⭐⭐⭐⭐ | 推荐片段，内容完整且有亮点 |
| 10-15 | B级 | ⭐⭐⭐ | 可选片段，有一定价值但需优化 |
| 5-10 | C级 | ⭐⭐ | 备选片段，建议与其他片段组合 |
| <5 | D级 | ⭐ | 不推荐，信息价值低 |

## 权重调整指南

不同类型的直播内容，需要调整权重配置：

### 场景1：技术分享类直播

**特点**：专业术语多、逻辑性强、情绪平稳

**推荐权重**：
```json
{
  "information_density": 0.40,    // ↑ 提高信息密度权重
  "emotion_peak": 0.10,           // ↓ 降低情绪权重
  "golden_sentence": 0.25,
  "topic_completeness": 0.20,     // ↑ 提高完整性权重
  "viral_potential": 0.05         // ↓ 降低传播权重
}
```

### 场景2：招聘宣讲类直播

**特点**：互动性强、共鸣点多、信息密度中等

**推荐权重**：
```json
{
  "information_density": 0.25,
  "emotion_peak": 0.25,           // ↑ 提高情绪权重
  "golden_sentence": 0.25,
  "topic_completeness": 0.10,     // ↓ 降低完整性要求
  "viral_potential": 0.15         // ↑ 提高传播权重
}
```

### 场景3：产品发布类直播

**特点**：金句多、传播导向、情绪峰值明显

**推荐权重**：
```json
{
  "information_density": 0.20,
  "emotion_peak": 0.30,           // ↑ 提高情绪权重
  "golden_sentence": 0.30,        // ↑ 提高金句权重
  "topic_completeness": 0.05,
  "viral_potential": 0.15         // ↑ 提高传播权重
}
```

## 高级策略

### 策略1：去重与合并

**问题**：滑动窗口可能识别出重叠片段

**解决方案**：
1. 按分数排序
2. 检测时间重叠（overlap > 50%）
3. 保留高分片段，丢弃低分重叠片段

```python
def remove_overlaps(highlights):
    unique = []
    for h in sorted(highlights, key=lambda x: x['score'], reverse=True):
        overlap = False
        for existing in unique:
            if calc_overlap(h, existing) > 0.5:
                overlap = True
                break
        if not overlap:
            unique.append(h)
    return unique
```

### 策略2：时长控制

**目标**：单个CUT时长控制在1-3分钟

**方法**：
- 过短（<60秒）：尝试扩展前后各5秒
- 过长（>180秒）：拆分为多个子片段
- 理想区间：90-120秒

### 策略3：金句锚定

**思路**：围绕金句构建完整片段

**步骤**：
1. 先识别所有金句位置
2. 以金句为中心，向前后扩展30秒
3. 检测该区间的话题完整性
4. 不完整则继续扩展，直至找到起止标志

### 常见问题

**Q1：识别出的片段过多（>20个）**

A：提高得分阈值，只保留A级以上片段：

```python
highlights = [h for h in highlights if h['score'] >= 15]
```

**Q2：识别出的片段过少（<5个）**

A：降低权重配置，或扩大滑动窗口：

```python
analyze_topic_completeness(segments, window_size=15)  # 默认10
```

**Q3：金句识别不准确**

A：手动标注金句，作为训练数据优化规则：

```python
golden_sentences = identify_golden_sentences(segments, manual_seeds=[
    "技术不是让5%的人锦上添花，而是让95%的人雪中送炭"
])
```
