# 小红书干货型文案模板库

小红书干货型内容的核心特征：**快速抓住用户注意力 → 提供实用价值 → 引导互动**

## 模板结构

所有干货型文案遵循四段式结构：

```
【开头】直击痛点/核心价值（1-2句话）
  ↓
【正文】结构化内容（1234分点 or 场景化描述）
  ↓
【金句】可提炼的短句（emoji强调）
  ↓
【结尾】行动号召（关注/收藏/评论区互动）
```

## 写作技巧

### 1. 开头黄金3秒法则

**目标**：3秒内让用户停下来

**公式**：
- 痛点共鸣：`你是不是也...`
- 数据震撼：`花了XX小时/对比了XX个...`
- 反常识：`❌ 大错特错！真相是...`
- 利益承诺：`5分钟学会/不花一分钱...`

**好例子**：
```
✅ "花了3小时整理的83分钟直播，精华都在这了"
✅ "你以为的校招 vs 真实的校招，差距太大了"
✅ "0基础也能看懂的AI原生公司判断标准"
```

**坏例子**：
```
❌ "今天给大家分享一下校招的一些经验"
❌ "最近参加了一个直播，觉得挺有收获的"
```

### 2. 正文结构化法则

**核心原则**：降低阅读成本

**工具**：
- 数字序号：1️⃣ 2️⃣ 3️⃣
- emoji图标：📍 ✅ ❌ 💡 🔥
- 分割线：`---`
- 加粗关键词：`**重点**`

**好例子**：
```
3个核心差异：

1️⃣ 招聘规模
快手：0-3年专项通道
字节：全球化大量HC

2️⃣ 文化氛围
快手：种地社（普惠价值观）
字节：追求极致（高速成长）

3️⃣ 技术栈
快手：推荐算法+音视频
字节：全栈+AI+国际化
```

### 3. 金句提炼法则

**目标**：让用户想截图转发

**公式**：
- 对比式：`不是...而是...`
- 比喻式：`XX就像YY`
- 数字式：`XX%的人不知道...`
- 行动式：`记住这一点：...`

**好例子**：
```
💡 "我们要的不是会写代码的人，而是能用技术改变生活的人"
💡 "技术的价值不是让5%的人锦上添花，而是让95%的人雪中送炭"
💡 "应届生的优势不是经验，而是可塑性"
```

### 4. 结尾互动法则

**目标**：提升完播率和互动率

**公式**：
- 提问式：`你觉得呢？评论区聊聊👇`
- 投票式：`A-选项1 B-选项2 C-选项3`
- 行动式：`点赞收藏！下次用得上🔖`
- 福利式：`关注我，持续分享[领域]干货`

**好例子**：
```
✅ "你更看重哪家公司？评论区投票👇
   A-快手 B-字节 C-美团"

✅ "收藏这条！校招季用得上🔖"

✅ "你还想知道哪些公司的内幕？留言告诉我💬"
```

## 小红书算法优化Tips

1. **标题前30字**：必须包含核心关键词
2. **emoji使用**：每段开头+金句处，提升视觉吸引力
3. **话题标签**：3-5个，精准匹配内容
4. **互动引导**：结尾必须有明确的行动指令
5. **完播率优化**：控制字数在500-800字（阅读时间30-60秒）
6. **封面图**：必须包含核心关键词文字
