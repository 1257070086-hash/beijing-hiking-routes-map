# 快手雇主品牌舆情监控平台

## 功能概览

| 功能 | 说明 |
|------|------|
| 📊 数据概览 | KPI 卡片、情绪饼图、7日趋势折线图、热词云、实时预警 |
| 📋 内容列表 | 多维筛选（平台/情绪/预警/关键词搜索）、预警内容高亮置顶 |
| 🚨 预警中心 | 集中展示所有待处理预警，支持一键「标记处理」 |
| ✏️ 手动录入 | 小红书内容录入表单，实时情绪预判，保存至本地 |
| ⚙️ 关键词管理 | 分三级（危机/负面/正面）自定义关键词，实时生效 |

## 使用方法

### 快速开始

直接在浏览器中双击打开 `index.html` 即可使用，无需任何服务器或安装。

> **注意**：首次打开可能因浏览器安全策略无法加载 `data/articles.json`。  
> 推荐用以下方式在本地启动简单服务器：

```bash
# Python 3
cd employer-brand-monitor
python3 -m http.server 8080
# 然后访问 http://localhost:8080
```

### 录入小红书内容

1. 打开「手动录入」页面
2. 填写帖子标题、作者、发布日期、内容摘要、原文链接
3. 内容会自动分析情绪，命中危机关键词时自动标记预警
4. 点击「保存到监控库」后立即出现在列表中

### 自定义关键词

打开「关键词管理」页面：
- **危机关键词**：命中即触发红色预警（如：裁员、维权、PUA）
- **负面关键词**：标记负面情绪，不触发预警
- **正面关键词**：标记正面情绪

### 数据结构

`data/articles.json` 每条记录的字段说明：

```json
{
  "id": "唯一ID",
  "platform": "微博|知乎|微信|小红书",
  "title": "标题",
  "content": "内容摘要",
  "url": "原文链接",
  "author": "作者",
  "published_at": "2024-04-08",
  "sentiment": "positive|negative|neutral",
  "sentiment_score": 0.82,
  "keywords_hit": ["命中的关键词"],
  "is_alert": true,
  "tags": ["标签1", "标签2"]
}
```

### 批量导入新数据

将新采集的内容追加到 `data/articles.json` 数组末尾，然后点击页面右上角「↻ 刷新数据」按钮。

## 平台说明

| 平台 | 数据来源 |
|------|---------|
| 微博 | 可通过 MediaCrawler 自动采集（需配置 cookie） |
| 知乎 | 可通过 MediaCrawler 自动采集 |
| 微信公众号 | 可通过公众号文章 URL 手动保存 |
| 小红书 | ⚠️ 仅支持手动录入（避免封号风险） |

## 注意事项

- 所有手动录入的小红书内容存储在浏览器 `localStorage` 中，清除浏览器数据会丢失
- 「标记处理」的预警记录也存储在 `localStorage` 中
- 关键词配置持久化存储，不会丢失
